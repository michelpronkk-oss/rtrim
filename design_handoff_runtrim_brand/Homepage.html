01The drift problem

AI agents are fast. They also drift.

Without a protocol, every run is a coin flip. Context resets between sessions, scope creeps quietly, and the audit trail ends at a Slack message. Six failure modes show up again and again.

Context reset

Every session starts blind

The agent forgets your conventions, the last run, and which files matter. You re-explain the codebase, again.

SESSION_NEW · memory: null
Scope creep

One task, twelve files

You asked to fix a webhook. It touched the auth layer, two configs, and a migration nobody approved.

DELTA · files_touched: 12 / 3
Token burn

Re-loading the same repo

Without scoped memory, the agent reads the world to do anything. Token bills compound silently, run after run.

USAGE · +38% vs scoped
Forbidden writes

It edited .env

Production secrets, migrations, and infrastructure should be off-limits by default. Most agents have no concept of off-limits.

VIOLATION · writes: .env.production
Unclear handoff

Is it actually done?

The agent says "complete." Tests are red, the diff is half-applied, and nobody flagged it. You find out at PR review.

FINISH · checks: skipped
No audit trail

What did it actually do?

Three runs, four branches, zero history of intent. You can read the diff, but you can't read the reasoning behind it.

02The RunTrim protocol

AI coding, turned into scoped execution.

Five stages. One contract. Any agent. RunTrim wraps your model of choice with memory, scope, stop rules, and a finish check, then writes the run to your dashboard.

01 / install
$ runtrim init
Drop the protocol into your repo. Conventions, allowed paths, forbidden files, finish checks.
02 / dispatch
$ runtrim go "task"
Compile the run contract. Load memory, lock scope, set the token budget, attach the finish check.
03 / execute
› agent
Claude, Codex, Cursor or any agent runs the guarded prompt. Stop rules trigger if it strays.
04 / verify
$ runtrim finish
Run the finish check. Tests, scope, diff size, forbidden writes. Pass or fail, no in-between.
05 / sync
↗ dashboard
Run, contract, diff, token spend, and verdict are written to your dashboard. Resumable next session.
